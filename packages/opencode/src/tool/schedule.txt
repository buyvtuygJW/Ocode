Manage deterministic qm-style background schedules (crons) — plain JSON in the global opencode config dir (schedules.json), NO LLM scoring, NO server. Actions: add (name + every: "<N>m"|"<N>h"|"<N>d"|"daily@HH:MM" + prompt [+ agent]) upserts a schedule; list shows all with next-run times; remove deletes by name; due lists the schedules whose time has come (execute each prompt, then call mark); mark records a completed run by name; export prints crontab/schtasks lines that run `opencode run "<prompt>"` so the OS scheduler executes them truly unattended. The built-in /schedule command runs everything that is due.
